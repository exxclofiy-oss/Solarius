# SUNFLARE Extended Sword — 1.21.11

The sword has a stretched, sharpened spear-point silhouette and a slightly longer wrapped grip. This is a **model/resource-pack-only** update: your existing Solarius 4.0 Paper JAR does not require replacing. All three skills and `/cooldown` stay unchanged.

Install **Solarius-Sunflare-Extended-ResourcePack-1.21.11.zip** into Minecraft Java `resourcepacks`, select it in Resource Packs, and place it above or replace older Solarius packs. To share it across the SMP, host this pack and set the server resource-pack URL and SHA-1.

To edit, open `models/blockbench/solar_sword.bbmodel` in Blockbench. The item model remains at `solarius:item/solar_sword`, so the same item rendering references are used. No JAR has been built or live-server tested as part of this visual update.
